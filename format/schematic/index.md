# SCH Schematic Type Document

This chapter details the format specification of the EasyEDA schematic file. Schematic files mainly consist of the following parts:

- [Common Format](/en/format/schematic/common.md): document header and canvas configuration.
- [Structural Elements](/en/format/schematic/structure.md): PART sub-library and GROUP combination.
- [Attributes](/en/format/schematic/attr.md): primitive attribute definitions.
- [Wires](/en/format/schematic/wire.md): wires, buses, and bus entries.
- [Text](/en/format/schematic/text.md): text elements.
- [Shapes](/en/format/schematic/shape.md): rectangles, polygons, circles, arcs, Bezier curves, ellipses.
- [Pins](/en/format/schematic/pin.md): pin definitions.
- [Components](/en/format/schematic/component.md): schematic component instances.
- [Objects](/en/format/schematic/obj.md): binary objects (images, etc.).
- [Tables](/en/format/schematic/table.md): tables and cells.
