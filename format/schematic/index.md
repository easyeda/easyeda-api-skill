# SCH Schematic Type Document

This chapter details the format specification of the EasyEDA schematic file. Schematic files mainly consist of the following parts:

- [Common Format](/en/format/schematic/common/): document header and canvas configuration.
- [Structural Elements](/en/format/schematic/structure/): PART sub-library and GROUP combination.
- [Attributes](/en/format/schematic/attr/): primitive attribute definitions.
- [Wires](/en/format/schematic/wire/): wires, buses, and bus entries.
- [Text](/en/format/schematic/text/): text elements.
- [Shapes](/en/format/schematic/shape/): rectangles, polygons, circles, arcs, Bezier curves, ellipses.
- [Pins](/en/format/schematic/pin/): pin definitions.
- [Components](/en/format/schematic/component/): schematic component instances.
- [Objects](/en/format/schematic/obj/): binary objects (images, etc.).
- [Tables](/en/format/schematic/table/): tables and cells.
