# PCB Format Document

This chapter details the format specification of the EasyEDA PCB file. PCB files mainly consist of the following parts:

- [Common Format](/en/format/pcb/common.md): document header, canvas, layers, physical layers, preferences, etc.
- [Partition Format](/en/format/pcb/partition.md): partition definitions.
- [Basic Primitives](/en/format/pcb/primitive.md): nets, primitive configurations, groups, silkscreen configurations, associations, attributes, etc.
- [Pads and Vias](/en/format/pcb/pad_via.md): pads and vias.
- [Shape Primitives](/en/format/pcb/shape.md): lines, arcs, polygon systems, polylines, fills, regions, copper pours, images, teardrops, etc.
- [Binary Objects](/en/format/pcb/obj.md): embedded objects.
- [3D Shell](/en/format/pcb/3d.md): shells, creases, entities, bosses.
- [Text System](/en/format/pcb/text.md): text.
- [Attributes](/en/format/pcb/attr.md): attributes.
- [Dimension Tools](/en/format/pcb/dimension.md): dimension annotations.
- [Footprint System](/en/format/pcb/component.md): component instances.
- [Design Rules](/en/format/pcb/rule.md): rule templates, rule definitions, rule selectors.
- [Panelization](/en/format/pcb/panel.md): panelization parameters.
