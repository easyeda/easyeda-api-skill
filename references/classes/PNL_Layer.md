# PNL\_Layer class

面板 / 工艺图层类

## Signature

```typescript
class PNL_Layer
```

## Remarks

面板的图层是固定的一套，用户不能加层也不能删层，这点和可以自由加层的 PCB 不一样。

每类图元只能放在特定的几个层上，放错会被拦下： - 文本：只能放打印层、遮盖层 - 矩形、椭圆、圆弧、折线 / 复合路径：可放打印层、遮盖层、板框层、槽孔层、背胶挖切层、灯光层、鼓包层 - 图片：只能放打印层 - 尺寸标注、辅助线、辅助点：只能放辅助层

材质外框层和「全部层」不对用户开放：前者是板子材料范围的边界，后者只在输出文件里用来追加图元。 创建或修改时传入不允许的层，接口直接返回 `false`<!-- -->，不会默默改到打印层——这种失败要调用方自己处理。
