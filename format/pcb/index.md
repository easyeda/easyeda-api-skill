# PCB Format Document

This chapter details the format specification of the EasyEDA PCB file. PCB files mainly consist of the following parts:

- [Common Format](/en/format/pcb/common/): document header, canvas, layers, physical layers, preferences, etc.
- [Partition Format](/en/format/pcb/partition/): partition definitions.
- [Basic Primitives](/en/format/pcb/primitive/): nets, primitive configurations, groups, silkscreen configurations, associations, attributes, etc.
- [Pads and Vias](/en/format/pcb/pad_via/): pads and vias.
- [Shape Primitives](/en/format/pcb/shape/): lines, arcs, polygon systems, polylines, fills, regions, copper pours, images, teardrops, etc.
- [Binary Objects](/en/format/pcb/obj/): embedded objects.
- [3D Shell](/en/format/pcb/3d/): shells, creases, entities, bosses.
- [Text System](/en/format/pcb/text/): text.
- [Attributes](/en/format/pcb/attr/): attributes.
- [Dimension Tools](/en/format/pcb/dimension/): dimension annotations.
- [Footprint System](/en/format/pcb/component/): component instances.
- [Design Rules](/en/format/pcb/rule/): rule templates, rule definitions, rule selectors.
- [Panelization](/en/format/pcb/panel/): panelization parameters.
